# GLThaiHome

Página principal de GL Thai.

Botón 1:
- Series → https://yeissan.github.io/GLThaiMiniApp/

Botón 2:
- Biblioteca → https://yeissan.github.io/GLThaiBooks/

Para agregar más opciones, edita `assets/app.js` y añade otro objeto dentro de `APPS`.

Publica este repositorio con GitHub Pages y configura el botón principal del bot para abrir esta URL.
